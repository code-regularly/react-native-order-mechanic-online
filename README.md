# Order Mechanic Online - A React-native Mobile App!

"Order Mechanic Online" is a cross-platform non-native mobile application for iOS & Android built using React-Native and JavaScript. This application was developed by 5 students under my leadership as an end-of-the-semester project at the university in 3rd year. The core idea of the app is to order mechanics online in a radius of 5 miles for minor car issues that require quick fixes.

## Credits & Project Timeline

While leading the software development of this project with my friends back in 2020, I wrote most of the code (~80%), developed most of the screens (~75%), implemented app navigation and data passing logic, managed Firebase connection via sockets - and a lot more. The remaining ~20% of the work was done by 4 of my peers, collectively.

## Project Technologies

The project relies on the following dependencies:

1. Firebase real-time NoSQL database (npm install firebase --save)
2. Formik forms for React-Native (npm install react-native-formik --save)
3. Yup for Formik form validation (npm install yup --save)
4. Stack navigation for screen components (npm install react-navigation-stack --save)
5. Drawer navigation for screen components (npm install react-navigation-drawer --save)
6. Tab navigation for screen components (npm install react-navigation-tabs --save)
7. Expo vector icons for creating icons and smart labels (npm install @expo/vector-icons --save)
8. Google maps for react-native to see mechanics in the 5-mile radius (react-native-maps --save)
